# Public evidence derivatives

These copies omit personal server paths, host addresses, and GPU identifiers from
historical records. Experimental measurements, outcomes, and numerical results
are retained. Original files remain unchanged in the local workspace.

The directory structure mirrors original output paths. For figure regeneration,
copy corresponding derivatives to those paths in a separate reproduction copy.
These support reading and plotting, not byte-identical historical provenance audits.
Raw datasets and generated client arrays are not included.
