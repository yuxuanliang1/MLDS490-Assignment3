# Local course references

This directory contains the supplied assignment handouts and course lecture/lab
PDFs. `mlds_assignment3.pdf` is the Assignment 3 specification; the Week 7/8 FL
materials and Week 7 Lab support the report's methodological discussion. Earlier
assignment/lecture PDFs are course context, not current experimental outputs.

These files are read-only reference inputs, not executable components. No package,
dataset setup, correctness command, or plot-generation command applies here.
See the [project README](../README.md) for implementation dependencies, data setup,
scientific validation commands, and output locations, and the
[report bibliography](../report/references.bib) for research/course citations.

The assignment requires a Canvas PDF report with the GitHub username, repository
name/URL, run instructions, labeled plots, discussion answers, edge cases,
quantitative correctness validation, a non-standard plot per part, and a proposed
three-month validation plan. Source code is submitted through the public GitHub
repository. The grading weights are implementation 5%, plots/discussion 10%,
edge cases/tests 75%, and formatting/readability 10%.

Do not assume course PDFs may be redistributed publicly. Retain them locally
unless permission allows publication; the standalone Overleaf report does not
require these PDFs to compile.
